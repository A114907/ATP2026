## Resumo

Criamos uma aplicação em python que coloca no monitor o seguinte menu de operações:
- 1: Criar uma turma;
- 2: Inserir um aluno na turma;
- 3: Listar a turma;
- 4: Consultar um aluno por id;
- 8: Guardar a turma em ficheiro;
- 9: Carregar uma turma dum ficheiro;
- 0: Sair da aplicação
