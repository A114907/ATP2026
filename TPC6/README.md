## Resumo

Cria uma aplicação Python que permita ao utilizador usar todas as funcionalidades pedidas nesta ficha, sendo elas:
- Calcular a temperatura média de cada dia;
- Guardar a tabela meteorológica num ficheiro;
- Carregar a tabela meteorológica de um ficheiro;
- Calcular a temperatura mínima mais baixa registada na tabela;
- Calcular a amplitude térmica de cada dia;
- Calcular o dia em que a precipitação registada teve o seu valor máximo;
- Dias com precipitação superior a um limite escolhido;
- Maior número de dias consecutivos com precipitação abaixo do limite escolhido;
- Gráficos da temperatura mínima, máxima e de pluviosidade;
